# defense_sample

로그라이크 **미로** 타워디펜스 (모바일, iOS/Android) — **재미 검증용 프로토타입**.

- 엔진: Godot 4.x
- 언어: GDScript (데이터 주도)
- 핵심 차별점: 타워 = 장애물. 적은 `AStarGrid2D`로 스폰→기지 경로탐색. 타워를 세워 적을 우회·순환시켜 더 오래 때린다. **출구를 완전히 막는 배치는 불가.**
- 런 구조: 단일 맵, 웨이브 1→40, 웨이브 사이 랜덤 상점, 웨이브 40 최종 보스 처치 = 런 승리(선택적 무한).
